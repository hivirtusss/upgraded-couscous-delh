  1200 devices — Firestore se fetch
══════════════════════════════════════════

1) Collection naam (default: "devices")
   File: constants/firebaseCollections.js
   Agar tumhara alag naam hai → FIRESTORE_DEVICES_COLLECTION badlo

2) Har document mein ye fields (koi bhi naam chalega):

   deviceId   (ya device_id / androidId / doc id)
   pin        (khali / open = bina PIN, number = PIN wala)
   label      (optional — naam)

   Example Firestore doc:
   {
     "deviceId": "8f3a9c1b2d4e5678",
     "pin": "4521",
     "label": "User 42"
   }

   Bina PIN:
   { "deviceId": "abc...", "pin": "" }
   ya pin: "open"

3) Rules (read allow):
   match /databases/{db}/documents/devices/{id} {
     allow read: if true;
   }

4) App
   - Firebase config txt → ON
   - ▶ Fetch 1200+ devices (Firestore)
   - Neeche: Sab / Bina PIN / PIN wale filter
   - 400-400 page se load (progress dikhega)

5) Agar 1200 se kam/zyada aaye
   - Collection naam check
   - Console mein kitni documents hain

6) Storage txt use karte ho?
   Neeche wala "Start fetch (Storage txt/zip)" use karo
