# Shuruaat — Day 1 (30 minute)

Yeh tumhara **pehla project**. Koi paise, install, coding background zaroori nahi.

## Step 1: File banao (5 min)

1. Phone ya laptop pe **Notes** / **Notepad** kholo **ya**
2. Is folder ki `index.html` copy karo apne phone/PC pe (GitHub se download bhi kar sakte ho).

## Step 2: Naam bharo (10 min)

`index.html` kholo. In jagahon pe apni baat likho:

- `<h1>` ke andar — **tumhara naam** (ya nickname)
- `tagline` wali line — jaise: *"Seekh raha hoon web aur chhoti freelancing"*
- "Mere baare mein" — 2-3 lines sach, short

`<!-- ... -->` wale comments hata sakte ho; unke andar likhna hai.

## Step 3: Browser mein dekho (2 min)

- **Laptop:** `index.html` pe double-click → Chrome/Edge mein khul jayegi.
- **Phone:** file ko kisi app se "Open with browser" (ya pehle laptop pe test).

## Step 4: Kal ka goal (15 min)

- Skills list mein **1 sachchi cheez** add karo (typing fast, Excel, etc.)
- Contact section mein **sirf tab** number daalo jab safe lage

## Agar atak jao

Yahan chat mein likho:

- `mera naam ___ hai`
- `tagline ___`

Main tumhare liye ready HTML bana ke de dunga.
